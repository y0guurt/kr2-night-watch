## Описание

Многостраничный учебный сайт компьютерного клуба «Ночной дозор». Посетитель может изучить игровые зоны и примерные технические конфигурации, посмотреть почасовые и пакетные тарифы, открыть подробное описание VIP-зоны, заполнить демонстрационную заявку на бронирование, посмотреть контакты и ответы на вопросы.

Название клуба — рабочее и может быть изменено. Контакты, характеристики и стоимость **демонстрационные**: они не представляют сведения о реальном заведении. Бронирование не передаётся на сервер, а служит учебной демонстрацией HTML-валидации и интерфейса.

## Технологии

- HTML5, семантические теги, подписи форм, адаптивные изображения (SVG);
- **Bootstrap v5.3.6**, подключён **локально**, файлы: `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`;
- CSS3 в `css/custom.css`: переменные, градиенты, пользовательская тема, адаптивные уточнения, видимый фокус;
- немного обычного JavaScript в `js/main.js` для демонстрационной валидации и предварительного расчёта стоимости;
- Git и GitHub (репозиторий и Pull Requests).

Никаких npm, React, Vue, базы данных и backend для запуска не требуется.

## Bootstrap-компоненты и сетка

В проекте применяются `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`, `navbar`, `navbar-toggler`, `collapse`, `card` и `card-body` (Bootstrap-карточки с собственными вариантами оформления), `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `carousel`, `accordion`, `table`, `table-responsive`, `toast`, а также Bootstrap utilities для отступов и выравнивания.

> Для карточек используются базовый Bootstrap-класс `card` и собственные классы `.zone-card`, `.tariff-card` — это осмысленная доработка визуального оформления.

## Примерная логика стоимости

Базовый тариф для зоны Standard:

| Пакет | Базовая цена за место |
| --- | ---: |
| 1 час | 220 ₽ |
| 3 часа | 590 ₽ |
| 5 часов | 890 ₽ |
| Ночь, 22:00–06:00 | 1 290 ₽ |

VIP Lounge: базовая цена × 1,5. Team Arena: базовая цена × 1,2 **за место**. Результат показывается в правой колонке страницы `order.html`. Все суммы — выдуманные учебные примеры.

## Валидация формы

- Поля со звёздочкой обязательны (`required`), настроены `type`, `minlength`, `pattern` и `label`.
- Дата не может быть раньше сегодняшней (локальная дата пользователя).
- Ночной пакет автоматически устанавливает время 22:00.
- При корректном заполнении показывается Bootstrap `toast` с ясным предупреждением, что бронь не создана и данные не отправлены.
- Быстрая заявка доступна через Bootstrap `modal`.

## Самостоятельные доработки сверх базовой методички

1. Оригинальная тёмная «киберспортивная» дизайн-тема с неоновыми акцентами, CSS-переменными и собственными состояниями элементов.
2. **Локальное подключение Bootstrap**: сайт открывается полностью офлайн.
3. Две дополнительные полноценные страницы: «Тарифы» и «Контакты».
4. Авторские SVG-иллюстрации игровых зон без внешних зависимостей.
5. Таблица сравнения оборудования, адаптивный `carousel` и FAQ через `accordion`.
6. Подсчёт демонстрационной стоимости и предварительное заполнение параметров заявки по ссылкам (`?zone=vip&tariff=5h`).
7. Доступность: видимый фокус, `alt`, `aria-label`, `label`, ссылка «Перейти к содержимому», поддержка reduced motion.
8. Отдельный контрольный список для практик №9, №10 и №11.

## Запуск

1. Распаковать ZIP.
2. Открыть папку `kr2-night-watch` в VS Code.
3. Открыть `index.html` в браузере или использовать расширение Live Server.
4. Никакая установка зависимостей не нужна: Bootstrap уже находится в папке `vendor/`.
5. Для проверки открыть все страницы, сжать окно браузера до ширины телефона и проверить меню, форму, модальное окно, карусель, FAQ.

## Пример Git-процесса по методичкам

Создание собственного удалённого репозитория — вручную на GitHub; имя может быть `kr2-night-watch`.

```bash
git init
git add .
git commit -m "chore: initialize Night Watch Bootstrap project"
git branch -M main
git remote add origin https://github.com/USERNAME/kr2-night-watch.git
git push -u origin main

git switch -c feature/bootstrap-components
# Внести изменения, проверить страницы
git add .
git commit -m "feat: add Bootstrap components and booking form"
git push -u origin feature/bootstrap-components
```

Затем создать Pull Request `feature/bootstrap-components → main` на GitHub и выполнить Merge. В зависимости от порядка собственной работы можно делать отдельные ветки для сетки, компонентов и финальной проверки.

## Публикация и сдача

1. Загрузить файлы в **отдельный** GitHub-репозиторий.
2. Убедиться, что присутствуют все HTML-файлы, `README.md`, локальный Bootstrap и исходные ресурсы.
3. По желанию включить GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.
4. Проверить переходы, модальное окно, FAQ и форму.
5. В СДО отправить **ссылку на итоговый GitHub-репозиторий**. Практики отдельно не сдаются.

## Ограничения

Это учебный **frontend**, а не сайт действующего клуба: контакты и адрес намеренно оставлены без вымышленных персональных данных, изображение карты условное, оплаты и реальной отправки бронирования нет. Для рабочего сайта понадобятся реальные сведения о клубе, политика обработки персональных данных и backend.
